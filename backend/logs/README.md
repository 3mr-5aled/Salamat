# Logs Directory

This directory stores application logs generated by Winston logger.

## Log Files

- `error.log` - Contains only error-level logs
- `all.log` - Contains all log levels (debug, info, warn, error)

## Important Notes

- **DO NOT COMMIT** log files to version control
- This directory is excluded in `.gitignore`
- Logs are automatically created when the application runs
- Old logs should be rotated/archived periodically

## Log Levels

- **error**: Error messages and exceptions
- **warn**: Warning messages
- **info**: Informational messages
- **http**: HTTP request logs
- **debug**: Detailed debug information (development only)

## Configuration

Logger configuration is in `src/utils/logger.utils.js`

- **Development**: Logs all levels to console and files
- **Production**: Logs warn and error levels only

## Viewing Logs

```bash
# View error logs
cat logs/error.log

# Follow all logs in real-time
tail -f logs/all.log

# View last 100 lines
tail -n 100 logs/all.log
```
